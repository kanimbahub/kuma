# Kuma

Application de centre d'appel multi-entreprise, s'appuyant sur XiVO (PBX, CC, Edge).

## Structure
- `frontend/` : écran agent et admin (React + TypeScript + Vite)
- `backend/` : API Kuma (Node.js + TypeScript + NestJS)
- `deploy/` : Docker Compose (dev et prod), configuration Caddy, surveillance

## Démarrer en dev
À venir : `docker compose -f deploy/compose.dev.yml up -d`
